# Fick

A new way to explore indie-made creative works.

> [!WARNING]
> This project is currently in development! Rest assured, advertised features works on a legacy branch that I will not push due to spaghetti code. If you want to contribute, please do so.

## How does Fick compare to AO3 and other OTW-Archive software sites like SquidgeWorld Archive?

Fick differs in a few key ways:

- Modernized UI while preserving the familiar OTW-Archive-style UX
- True Progressive Web App (PWA) support, including offline reading to help mitigate issues caused by server downtime
- Improved security features, including TOTP 2FA and security key support
- Improved mobile UX for browsing and reading on smaller screens

## Getting Started

To get started, install dependencies:

```sh
pnpm install
```

To run in development mode:

```sh
pnpm run dev:backend
pnpm run dev:frontend
```
